# 休息提醒工具 V1.19 使用说明

**休息提醒工具** 是一款用于防止长时间面对电脑、帮助劳逸结合的桌面应用。软件支持自定义工作与休息时长、桌面倒计时悬浮窗、锁屏休息以及延后提醒等功能。

## 使用指南

### 1. 基础配置与启动

1. **设置工作与休息时间**：
   - **休息时间间隔**：设置连续工作多长时间后需要休息（例如：60 分 0 秒）。
   - **休息时间长度**：设置每次休息的时长（例如：1 分 0 秒）。
2. **开机自启**：勾选“开机自动启动”，软件将在每次开机时自动在后台运行。
3. **开始/停止计时**：
   - 点击 **【开始计时】**：软件开始倒计时，并自动生成桌面悬浮小窗口。
   - 点击 **【终止计时】**：暂停并重置当前的所有计时任务。
   - 点击 **【重新开始计时】**：放弃当前周期，重新开始一轮工作计时。

### 2. 悬浮窗口与颜色个性化

- **打开主界面**：在桌面右上角（或自定义位置）找到悬浮倒计时小窗口，**双击小窗口** 即可快速调出主界面。
- **位置拖拽**：按住鼠标左键可将悬浮窗口拖拽到屏幕任意位置，软件会自动记忆你的偏好位置。
- **颜色设置**：
  - 点击 **【选择背景】**：自定义悬浮小窗的背景色。
  - 点击 **【选择字体】**：自定义倒计时文字的颜色。
  - 点击 **【恢复默认】**：一键还原为默认配色（蓝色背景 + 紫色文字）。

### 3. 休息提醒与延后机制

在工作倒计时**还剩 1 分钟**时，屏幕中央会弹出提醒窗口并播放语音提示：

- **【立即休息】**：提前结束工作，直接进入全屏锁屏休息状态。
- **【延后 5 分钟】/【延后 8 分钟】**：将当前工作时间延长指定时长。
  > **注意**：每个工作周期**最多只允许延后 3 次**。超过 3 次后延后按钮将失效，倒计时结束时将自动进入强制锁屏。

### 4. 托盘与后台运行

- **最小化与关闭**：在计时状态下，关闭主窗口或最小化会自动隐藏至系统右下角托盘。
- **托盘右键菜单**：
  - **打开主窗口**：调出程序控制界面。
  - **退出**：完全退出休息提醒程序。
